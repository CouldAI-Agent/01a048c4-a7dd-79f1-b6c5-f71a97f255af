# MARZI MEDIA HR

A professional HR Management application built with Flutter.

## Features

**HR Manager:**
*   HR Dashboard with overview metrics (Total Employees, Present, Absent, On Leave, Pending Leave Requests).
*   Employee management (Add, edit, view profiles).
*   Attendance tracking and monthly records.
*   Leave management (Approve/reject requests, view balances).
*   Work timing management.
*   Employee documents.
*   Notifications & announcements.

**Employees:**
*   Employee login and personal profile view.
*   Daily check-in and check-out.
*   Attendance history tracking.
*   Leave application and status checking.
*   Receive HR announcements.

## Tech Stack
*   Flutter (Cross-platform support: iOS, Android, Web, Desktop)
*   Provider (State Management)
*   Supabase (Ready for backend integration)

## Setup
1. Run `flutter pub get` to install dependencies.
2. Run `flutter run` to launch the app on your preferred device.
